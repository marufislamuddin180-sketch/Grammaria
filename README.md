# Grammaria: The Quest for Perfect Syntax

A retro fantasy educational RPG built with React 19, TypeScript, Vite, and Tailwind CSS. Players battle language-distorting monsters across 5 perilous dungeons to restore grammatical order to the realm of Grammaria.

## ⚔️ Game Overview

- **The World**: The "Syntax Error" curse has mutated corrupted sentences into vicious monsters.
- **Hero Classes**:
  - **Syntax Knight**: Resilient guardian with high HP (120 HP) wielding the *Blade of Proper Agreement*.
  - **Vocab Mage**: High spell damage specialist (40 Base DMG) casting *Lexical Surge*.
  - **Punctuation Rogue**: Agile combatant with extra potions (3x Elixir) throwing the *Semicolon Dagger*.
- **5 Monster Encounters**:
  1. *Typo Goblin* (Tier 1) - Border pass miscreant.
  2. *Tense-Twisting Troll* (Tier 1) - Ancient bridge guardian scrambling timeframes.
  3. *Comma Splice Dragon* (Tier 2) - Run-on sentence firebreather.
  4. *Dangling Modifier Chimera* (Tier 2) - Multi-headed ambiguous beast.
  5. *The Great Chaos Overlord (Passive Voice Demon)* (Tier 3) - Master of semantic chaos.
- **Combat & Education Engine**:
  - Turn-based battles where choosing the correct grammatical sentence slashes the enemy.
  - Immediate educational breakdown explaining the grammar rule behind each choice.
  - Item management with *Elixir of Eloquence* potions.
  - Level progression, EXP scaling, health restoration, and potion loot drops.
  - Interactive Grimoire & Bestiary reference book for all grammar rules and monsters.
  - Synthesized 8-bit retro sound effects via Web Audio API.

## 🛠️ Development & Build

# Run local dev server (port 3000)
